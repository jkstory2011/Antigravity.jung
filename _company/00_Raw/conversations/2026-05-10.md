1.  **(충격/질문형):** "혹시 이 물건이 그냥 쓰레기로 버려진다고 생각하셨나요? 반품된 옷 한 벌에 숨겨진, 수십억짜리 돈의 흐름을 아십니까?"
2.  **(통계 기반):** "지금 대한민국 온라인 쇼핑에서 발생하는 '반품 비용' 총액. 상상 이상입니다. 이 거대한 폐기물 더미가 사실은 가장 혁신적인 골드 마인입니다."
3.  **(공감/스토리텔링형):** "주문했는데 안 맞아서, 혹은 입어보고 싫어서... 쓰레기가 되어 돌아오는 물건들. 이 복잡하고 돈이 새는 과정을 누가 해결할까요?"

#### 🎣 후크 (Hook) 3가지

2.  **(비교/충격형):** "당신의 동네 골목길은 사실 거대한 물류 실험장입니다. 짐 하나 옮기는 게 이렇게 힘든 건지, 그 속사정을 공개합니다."
3.  **(기술/미래 제시형):** "지금까지의 배송 방식으로는 더 이상 안 됩니다. 미래의 택배는 트럭이 아니라 로봇과 드론일 겁니다."

#### 📝 스크립트 아웃라인 (총 길이: 9~12분 예상)
*   **[도입]** '오늘 도착' 문구를 보여주며 시작. 소비자의 기대감(Instantaneity)을 극대화하고, 이 요구가 물류 시스템에 가하는 압박감을 시각적으로 표현한다. **(후크 활용)**
*   **[본론 1: 전통적 한계]** 기존의 대형 트럭 중심 운송이 도심에서 직면한 병목 현상 설명 (교통 체증, 주차 문제, 소형 패키지 폭증). 물리적인 '거리'와 '시간'의 제약.
*   **[본론 2: 혁신적 솔루션 - 마이크로 풀필먼트]** **MFC(Micro Fulfillment Center)**나 지역별 소규모 물류 거점(Last Mile Hub) 구축 사례를 집중 조명한다. 대형 창고에서 골목까지의 최단 경로 설계가 중요함을 강조.
*   **[본론 3: 미래 기술의 결합]** 오토바이/자율주행 배송 로봇, 드론이 어떻게 이 마지막 1km 구간을 혁신하고 있는지 실제 작동 영상과 함께 보여준다. 사람이 아닌 기계가 해결하는 효율성 극대화 과정을 설명한다.

### 🎥 3편. 창고 속 AI: 인간이 놓치는 효율의 비밀

## 1. Airflow DAG – 매일 데이터 수집 스크립트 (Python)  
**경로:** `dags/data_collection.py`  

```python
from datetime import datetime, timedelta
import requests
import json
import os

from airflow import DAG
from airflow.providers.http.sensors.http import HttpSensor
from airflow.operators.python import PythonOperator
from airflow.providers.amazon.aws.hooks.s3 import S3Hook

DEFAULT_ARGS = {
    "owner": "jkstory",
    "depends_on_past": False,
    "email_on_failure": False,
    "email_on_retry": False,
    "retries": 1,
    "retry_delay": timedelta(minutes=5),
}

def fetch_and_store(**context):
    """
    외부 API에서 JSON 데이터를 가져와 S3에 저장.
    """
    api_url = os.getenv("DATA_API_URL", "https://jsonplaceholder.typicode.com/posts")
    response = requests.get(api_url, timeout=30)
    response.raise_for_status()
    data = response.json()

    # 파일명: data_YYYYMMDD.json
    date_str = datetime.utcnow().strftime("%Y%m%d")
    filename = f"data_{date_str}.json"

    # S3에 업로드
    s3_hook = S3Hook(aws_conn_id="aws_default")
    s3_bucket = os.getenv("DATA_S3_BUCKET", "jkstory-data-bucket")
    s3_key = f"daily/{filename}"
    s3_hook.load_string(
        json.dumps(data, indent=2),
        key=s3_key,
        bucket_name=s3_bucket,
        replace=True
    )
    context['ti'].xcom_push(key="s3_path", value=f"s3://{s3_bucket}/{s3_key}")

dag = DAG(
    "daily_data_collection",
    default_args=DEFAULT_ARGS,
    description="매일 외부 API에서 데이터를 수집해 S3에 저장",
    schedule_interval="0 2 * * *",  # UTC 기준 새벽 2시
    start_date=datetime(2024, 1, 1),
    catchup=False,
)

# ① API 가용성 확인
check_api = HttpSensor(
    task_id="check_api_up",
    http_conn_id="data_api_conn",   # Airflow Connections에 정의
    endpoint="",                    # 루트 호출
    response_check=lambda response: response.status_code == 200,
    poke_interval=30,
    timeout=300,
)

# ② 데이터 수집 및 저장
collect_task = PythonOperator(
    task_id="fetch_and_store",
    python_callable=fetch_and_store,
    provide_context=True,
)

check_api >> collect_task
```

## 2. GitHub Actions CI/CD – Airflow DAG 배포

```yaml
name: Deploy Airflow DAG

on:
  push:
    branches: [ main ]
    paths:
      - 'dags/**'
      - '.github/workflows/deploy_airflow.yml'

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repo
        uses: actions/checkout@v4

      - name: Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      # Airflow 가상환경 설정(선택)
      - name: Install dependencies (if any)
        run: |
          pip install --upgrade pip

      - name: Deploy DAG to Airflow
        env:
          AIRFLOW_HOST: ${{ secrets.AIRFLOW_HOST }}
          AIRFLOW_TOKEN: ${{ secrets.AIRFLOW_TOKEN }}
        run: |
          # Airflow REST API를 사용해 DAG 파일 업로드
          curl -X POST \
            -H "Content-Type: multipart/form-data" \
            -F "file=@dags/data_collection.py;filename=data_collection.py" \
            "${AIRFLOW_HOST}/api/v1/dags/daily_data_collection/refresh" \
            -u admin:${AIRFLOW_TOKEN}

      - name: Verify DAG deployment
        run: |
          echo "Deployment complete. Check Airflow UI."
```

- `DATA_API_URL`, `DATA_S3_BUCKET` – `.env` 혹은 Airflow Connections에 저장.  
- GitHub Secrets: `AIRFLOW_HOST`, `AIRFLOW_TOKEN` (Airflow 인증 토큰).
